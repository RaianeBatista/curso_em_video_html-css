Trabalhando com fontes

No CSS, tem-se disponíveis as seguintes medidas:

A recomendação oficial do W3C é de se usar as medidas px e em.

  • Medidas Absolutas
    • Centímetros (cm)
    • Milímetros (mm)
    • Polegadas (in)
    • Pixel (px)
    • Ponto (pt) — tipografia de papel, não recomendado para telas
    • Paica (pc) — tipografia de papel, não recomendado para telas
  • Medidas Relativas
    • em — relativa ao tamanho natural da fonte
    • ex — relativa à altura x de uma fonte
    • rem — relativa ao root da página (html)
    • vw — relativa à largura da viewport/tamanho da tela
    • vh — relativa à altura da viewport/altura da tela
    • % — porcentagem

Atenção!

A medida em parte do tamanho padrão de 16px do CSS.

  • 1em = 16px
  • 2em = 32px
  • 0.5em = 8px
  • 1.5em = 24px (16px * 1.5em)

Importante

Para usar as fontes em negrito no CSS:

font-weigh: as fontes possuem peso de 100 até 900, bold, bolder, lighter, normal.

Para usar as fontes em itálico no CSS:

font-style

Para usar as fontes em sublinhado no CSS:

text-decoration: underline

O que é a propriedade Shorthand? (shorthand font)

Significa condensar todas as confiugurações em uma única linha no CSS

Na seguinte ordem:

  1. font-style
  2. font-weight
  3. font-size
  4. font-family

Observe abaixo um exemplo de shorthand:

h1 {
font: italic bolber 3em 'Work Sans', sans-serif;
}

Outro exemplo

h2 {
font: bold 2em 'Work Sans', sans-serif;
}

A ordem no shorthand deve ser obedecida rigorosamente.
